¿Cómo usar este panel? (clic para expandir)
  1. Filtrá los casos con más riesgo usando el botón “Requieren revisión”: muestra documentos donde el sistema detectó algo raro (0 reemplazos, alertas automáticas).
  2. Hacé clic en un documento para abrir la comparación página por página: a la izquierda el original, a la derecha el anonimizado.
  3. Una vez revisado, marcalo con uno de los botones de la barra superior:
    • Aprobado — anonimización correcta, apto para entregar.
    • Necesita corrección — hay nombres sin tachar o placeholders mal ubicados; requiere retoque manual.
    • Rechazado — no sirve (p. ej. anonimizó jurídicas por error, o el PDF original estaba corrupto).
    • Pendiente — aún no revisado.
  4. Si querés revisar absolutamente todo (máxima fiabilidad), usá el filtro “Todos” y recorrelos de a uno.
  5. El estado se guarda automáticamente en {{ folder }}/_review_state.json. Podés cerrar el navegador y retomar después.
